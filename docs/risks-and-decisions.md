# 风险与决策 v1

记录本轮已做技术决策、替代方案（含维护成本与迁移影响）、未确定问题，以及验收风险。供架构与验收评审。

---

## 1. 已做决策（及理由）

| 决策 | 选择 | 理由 |
|------|------|------|
| 语言/前端 | TypeScript + React | 任务书拟定；前后端同语言，降低上下文切换成本 |
| 后端形态 | 模块化单体（Node/TS） | 约束 7：避免过早微服务；依赖单向，未来按需拆 Executor/Connector |
| 存储 | SQLite（Node 内置 `node:sqlite`） | 零额外依赖、单文件易备份迁移、完全归工作站所有（约束 1/6/9）；未来可换 Postgres，接口不变 |
| 模型接入 | 适配器模式 + 统一 `ModelGateway` | 约束 2/4：模型只提调用，程序裁决；双服务商复用同一编排（验证 B） |
| 工具权限 | 只读自动批准、副作用显式授权 | 约束 4：防止模型越权；与「不擅自烧录/改工程」一致 |
| 验证手段 | `node:test` + `tsx` 真实运行 | 契约与真实进程验证可执行、可复现；结果见 validation-report |
| 凭据 | 仅环境变量注入，`.env` 不进 Git | 约束 9：前端/文件/日志/仓库均无明文密钥 |

> 技术栈可提替代方案，但需在评审说明维护成本与迁移影响（见 §2）。

## 2. 替代方案与维护成本/迁移影响

| 维度 | 候选 | 维护成本 | 迁移影响 |
|------|------|----------|----------|
| 后端语言 | Python (FastAPI) | 中（需另建类型体系，前后端类型不同步） | 模型/工具接口需重写；核心数据模型可复用 JSON |
| 后端语言 | Rust (Axum) | 高（开发慢、招聘/协作面窄） | 性能最优但迭代慢；适配层需重新实现 |
| 存储 | Postgres | 低（SQL 兼容）；但需运维/容器 | SQLite→PG 仅需替换 `persistence` 实现，实体与 schemaVersion 策略不变 |
| 桌面壳 | Electron | 中（包体大、资源占用高） | 复用 Web，成本低 |
| 桌面壳 | Tauri | 中（Rust 侧需维护，但轻量） | 复用 Web + 本地执行节点更省资源，推荐评估 |
| 移动端 | 原生 (RN/Flutter) | 高 | 仅首版 Web 响应式即可覆盖，原生后置 |

**结论建议**：维持 TS/React/Node/SQLite 基线；远程部署时优先把 SQLite 替换为 Postgres（迁移面最小），桌面壳评估 Tauri。

## 3. 未确定问题（提交评审）

1. **主 STM32 工具链**：CubeIDE（免费、CLI 文档清晰）vs Keil（商业、UV4 `-b` 无头）。建议 CubeIDE 优先。需用户确认。
2. **飞书个人接入形态**：个人需建「团队/企业」+ 自建应用 + OAuth `user_access_token`；或评估 Lark CLI（`npx @larksuite/cli`）是否更省。需用户决定。
3. **EDA 集成深度**：专业版无 headless API，依赖编辑器内扩展 + JSON 导入导出。是否自研扩展待定。
4. **桌面/移动端路线**：Tauri vs Electron；移动端首版是否仅响应式。待定。
5. **多模型路由**：手动选择 + 可配置默认，还是按任务/成本自动路由。首版建议手动。
6. **凭据保险库**：环境变量本轮够用；远程部署建议接系统密钥库（OS keychain / 云服务 KMS）。

## 4. 验收风险

| 风险项 | 影响 | 缓解 |
|--------|------|------|
| 真实 STM32 构建阻塞（本机无工具链/样例） | 验收「构建」项无法 通过 | 已文档化无头命令（C4）并标记 阻塞；待安装工具链+样例后补真实构建 |
| EDA 无 headless API | 深度集成受限 | 走扩展 API + 文件导入导出（不依赖浏览器自动点击） |
| 飞书需建应用 + 用户授权 | 真实读取需授权条件 | 本轮只调研+配置步骤；有授权再补真实读取 |
| 模型真实调用无凭据 | 双服务商真实流程未验证 | 以契约/编排测试证明流程，真实调用标记 未验证 |
| 密钥意外落入日志/前端 | 违反约束 9 | `.gitignore` 排除 `.env`；`Connection` 仅存引用；CI 加密钥扫描 |

## 5. 范围边界（重申，任务书 七）

本轮不开发完整 UI、不部署生产、不发布网站、不真实烧录、不实现完整 PCB 编辑器、不引入复杂多 Agent 系统。完成后提交证据，等待架构与验收评审。
